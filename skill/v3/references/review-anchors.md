# 薄弱点标注与批注锚点

> v3 新增。对应 SKILL.md 的**阶段 3.5 标薄弱点**、**铁律 7/8**。
> 解决的问题：v2 的产物"通篇语气一样自信"，人工审阅时分不清哪句查证过、
> 哪句是推的，于是审阅变成"大海捞针"，问题靠人自己找。
> 本文的例子全部来自 `output/v2/human-edited.md` 的真实批注。

## 核心思路

把人的工作从 **"从头挑错"** 改成 **"对锚点逐条确认"**。

v2 的 4 处批注里，有 3 处是"AI 用笃定的口吻写错了"——如果 AI 当时能对自己
没把握的地方举一下手，这 3 处根本不用人去找。

## 一、置信度分级

起草完成后，**逐段**给自己打分：

| 级别 | 判据 | 处理 |
| --- | --- | --- |
| **高** | 有直接来源（官方手册原文 / 用户输入原文），且能指出出处 | 不标锚点 |
| **中** | 来源是二手（博客、教程），或来源与结论之间需要一步推理 | 标锚点 |
| **低** | 只有印象，或来源之间互相冲突 | 标锚点，或按铁律 1 写 `⚠️待核实` |

判断口诀：**"这句话我能点出出处吗？"** 点不出的，至少是"中"。

## 二、锚点写法

在正文中、可疑句的**后面**，插入 HTML 注释（渲染时不显示，但审阅 markdown 时可见）：

```markdown
`impl` 参数通常传 NULL，表示使用默认 provider 的实现。
<!-- 待确认：3.0 里 impl 是否可传 provider 取到的 EVP_CIPHER？我按「可传」写的，请核对。 -->
```

规则：

- 一句话说清**我为什么举手** + **需要人确认什么**
- 锚点紧贴可疑句，不许集中堆到段落末尾或文末
- 锚点**只用在"中/低"置信度**处，不许为了显得严谨而滥标

## 三、好/坏对照（来自 v2 的真实批注）

v2 的 4 处批注，如果 v3 重写，应该在成稿时就带锚点：

**批注 1 · impl 参数绝对化**

- v2 原话：`impl` 参数必须传 NULL。
- v2 问题：把"通常"写成了"必须"。
- v3 应写成：

```markdown
`impl` 参数通常传 NULL，表示使用默认 provider 的实现。
<!-- 待确认：impl 在 3.0 是否可传从 provider 取到的 EVP_CIPHER？我倾向"可传"，但没找到直接例子，请确认。 -->
```

**批注 3 · 前后不自洽**

- v2 原话：前一句"IV 不必保密但必须不可预测"，后一句"不像 CBC 那样额外要求 IV 保密"。
- v2 问题：两句自相矛盾。
- v3 应写成：起草时就按**铁律 8** 检查——写"CBC 要求 IV X"时回头看一眼本段有没有定义过 X，
  不一致就当场改，不留到人工发现。

**批注 4 · 越界占位**

- v2 原话：正文末尾挂 `⚠️待核实：教材是否给出了选型指引`。
- v2 问题：选型指引不在提纲要求内，属于自己加戏。
- v3 应写成：按**铁律 7**，提纲没要求的直接不写，**不挂占位**。

## 四、`self-review.md` 清单

标锚点之外，另出一份 `output/vN/self-review.md`，把全文薄弱点汇总成表，
让人不用翻正文也能一眼看到要确认什么：

```markdown
# vN 自查清单（待人工确认项）

| # | 位置 | 我的置信度 | 待确认什么 | 建议 |
| --- | --- | --- | --- | --- |
| 1 | 总结·4.5 | 中 | impl 传 NULL 与传 provider 实现的行为差异 | 若不展开，可删括号说明 |
| 2 | 实践·问题1 步骤3 | 中 | 7 字节明文开填充输出 16 字节是否算"正常" | 请确认表述 |
```

- 清单里每一条都要能在正文里找到对应的 `<!-- 待确认 -->` 锚点（**一一对应**）
- 清单**不进报告正文**，只作为 `output/vN/` 的独立文件，交给用户审阅

## 五、自查时怎么用

阶段 3 自查的最后一条（自洽性）和阶段 3.5 配合：

1. 先按阶段 3 的 13 条自查结构/精度/自洽；
2. 再逐段标置信度，把"中/低"的位置落成锚点 + 清单；
3. 交付时，明确告诉用户：**"请优先看 `self-review.md` 的 N 条待确认项"**。

## 速查

| 看到自己写下 | 立刻问 |
| --- | --- |
| 「必须」「一定」「都要」「不能」「总是」 | 能说出成立条件吗？说不出就加限定词 |
| 引用了某标准/某句"原话" | 我亲眼看到出处了吗？没有就标锚点 |
| 同一概念第二次出现 | 和第一次的说法一致吗？（自洽） |
| 想补一个提纲没写的内容 | 是提纲要求的吗？不是就删 |
