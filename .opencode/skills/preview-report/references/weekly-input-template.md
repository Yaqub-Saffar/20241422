# 第 N 周 · 输入模板

> 用法：Skill 在阶段 0 会逐项问上面这些问题。拿到答案后，把内容整理进本文件，
> 存为 `input/weekNN.md`（N 为周次），并与报告一起提交 git。
> 这个文件的作用是**留痕**：让"这一轮我到底给了 AI 什么"可追溯。
