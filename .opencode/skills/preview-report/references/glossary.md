## 一、通用规则

1. **全课程一个概念一个词**。定了「非对称加密」就不再写「公钥加密体制」。
2. **术语首次出现给中英对照**：`中文（English / 缩写）`，例：`消息摘要（Message Digest）`。
   首次出现之后只写一种，不再重复对照。
3. **缩写在首次出现时给全称**：`OAEP（Optimal Asymmetric Encryption Padding，最优非对称加密填充）`。
4. **章节号、标准号原样保留**，不做归一化（用户写 `5.2` 就是 `5.2`，写 `GB/T 32905-2016` 就照抄）。

## 三、跨周复用检查

起草新一周时，对本周涉及的**每一个**概念：

1. 在词表里查有没有 → 有，就按「统一写法」写；
2. 没有 → 补录一行，再写；
3. 写完扫一遍全文，确认同一概念从头到尾一个写法，且首次出现带了中英对照。

历史和将来会反复出现的概念（如「非对称加密」「消息摘要」），
**优先按本表定死**，避免第 N 周和第 N+1 周各写各的。
